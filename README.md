# 🏙️ The Skyline Problem

## 📌 Project Description
**The Skyline Problem** is a classic algorithmic challenge that focuses on generating the outline (skyline) of a city given a list of rectangular buildings.  
The goal is to compute the city silhouette as viewed from a distance, using an efficient and optimized approach.

**Problem source:** [LeetCode - The Skyline Problem](https://leetcode.com/problems/the-skyline-problem/description/)

---

## 🛠️ Technologies
- **Language:** C++
- **Framework:** Qt
